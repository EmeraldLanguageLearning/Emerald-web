# Emerald Tools (web)

The four Emerald Language Learning tools as a website: open it in Safari on an iPad (iOS 10.3 or later) and tap **Share → Add to Home Screen** to install it like an app.

This repository is generated from the private Emerald-tools project; edit the tools there, not here.
